# Python & AI/ML Learning Assignments

A structured collection of hands-on coursework from my journey learning Python and
applying it across Generative AI, LLMs, NLP, and classical machine learning. Each
top-level folder is a self-contained set of progressively-built assignments with
runnable notebooks and scripts.

## Contents

| Folder | Focus |
| --- | --- |
| `PYTHON` | Core Python: functions, OOP, exception handling, file I/O, functional tools (map/filter/lambda) |
| `MACHINE LEARNING ASSIGNMENTS` | Classical ML: data cleaning, regression, and model evaluation on real datasets |
| `NLP` | Natural language processing fundamentals |
| `BASICS LLM` | Working with large language models |
| `LANGCHAIN A21-22` | LLM orchestration with LangChain |
| `OLLAMA A23-24` | Running and prompting local models via Ollama |
| `CHATBOT` | Building a conversational assistant |

## Tech

Python 3.11 | Jupyter | scikit-learn | pandas | NumPy | LangChain | Ollama | LLMs

## Running

Most assignments are Jupyter notebooks:

    pip install -r requirements_backup.txt
    # open any ASSIGNMENT_*.ipynb in VS Code or Jupyter and run the cells top to bottom
