- Project Overview
Yeh project ek Data Analyst trainee assignment ka part hai jisme Pandas library ka use karke data manipulation tasks perform kiya hai. Is assignment ka main objective Series aur DataFrames ke structure ko samajhna, data filtering, grouping, aur basic visualization techniques ko master karna tha.

- Key Features

1. Efficient Data Handling: Pandas ki vectorized operations ka use karke data processing ki gayi hai bina kisi explicit loops ke.
2. Logging over Printing: Har output ko logger.info() ke through display kiya gaya hai.
3. Built-in Visualizations: Bina kisi external library (like Matplotlib) customization ke, Pandas ke direct plotting wrappers ka use kiya gaya hai.

- Task Details & Logic
Task 1. (Series Basics): List se Pandas Series create ki aur metadata attributes (index, dtype) aur positional slicing (first/last elements) ko explore kiya.

Task 2 (Math Operations): Scalar values ke saath mathematical operations (addition, multiplication) perform karke "Broadcasting" ka concept apply kiya.

Task 3 (Functional Pandas): Aggregations (Mean, Max, Sum) use kiye aur lambda function ke through passing status calculate karke boolean counting ki.

Task 4 (DataFrame Creation): Dictionary ko tabular format (DataFrame) mein convert kiya aur .shape aur .columns ke through structural audit kiya.

Task 5 (DF Functions): .info() aur .describe() se statistical profiling ki, data ko sort kiya, aur index reset karke data integrity maintain ki.

Task 6 (Filtering): Boolean Indexing ka use karke specific conditions (e.g., Marks > 75, Subject == Math) par data filter kiya.

Task 7 (Grouping): groupby() function ka use karke subject-wise average marks, student count, aur maximum scores analyze kiye.

Task 8 (Plotting): kind='bar', 'line', aur 'hist' parameters use karke data distribution aur trends visualize kiye.

Task 9 (Sales Analysis): Ek mini use case jisme total revenue, average, peak performance day find kiya aur visualization ke through insights generate kiye.

- How to Run
Prerequisites: Aapke system mein Conda (Python 3.11.14) aur Jupyter Notebook environment setup hona chahiye.
Install Pandas: pip install pandas
Run Notebook: .ipynb file ko open karein aur cells ko sequence mein execute karein.
Logs: Outputs aapko Jupyter cell output area mein formatted logs ke roop mein dikhenge.
