## Project Overview

Yeh project ek Data Analyst trainee assignment ka part hai. Iska main objective NumPy library ka use karke basic mathematical computations, array operations, aur statistical analysis karna tha. as usual standard `print` statements ki jagah `logging` module ka use kiya aur code ko Jupyter Notebook mai kiya hai.

## Key Features

- **Vectorized Operations:** Kahin bhi loops (for/while) ka use nahi kiya gaya hai, NumPy ki internal speed ka fayda uthane ke liye.
- **Logging:** Har output `logger.info()` ke through display hota hai.
- **Deep Documentation:** Har code block mein **What, Why, aur How** logic explained hai.

## Task Details & Logic

1. **Task 1 (Array Creation):** 1D, 2D (3x3), aur list-based arrays create kiye hain metadata (shape, dtype) check karne ke liye.
2. **Task 2 (Math Operations):** Element-wise Addition, Subtraction, Multiplication, aur Division perform kiya hai.
3. **Task 3 (Formulas):** Square root, Exponential, aur Natural Log apply kiye hai.
4. **Task 4 (Aggregation):** Matrix mein Row-wise aur Column-wise sums aur global Min/Max find kiya hai.
5. **Task 5 (Core Statistics):** Mean, Median, Variance, aur Standard Deviation calculate karke data ki dispersion check kari hai.
6. **Task 6 (Percentiles & Sorting):** Data ko sort karke 25th, 50th, aur 75th percentile (Quartiles) nikale hai.
7. **Task 7 (Sales Analysis):** Ek real-world mini use case jisme weekly sales performance aur volatility check ki hai.
